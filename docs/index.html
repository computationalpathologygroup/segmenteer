Segmenteer provides a common workflow for tissue segmentation on whole-slide images, optional evaluation, and visual inspection of results on any dataset.

Interactive viewer

Inspect the experiment visually.

01

Overview

A consistent experimental workflow.

Run segmentation on your WSI cohort, evaluate predictions when reference data are available, and inspect the same experiment visually with or without ground truth.

  1. Segment

    Generate tissue-region predictions for the selected whole-slide images.

  2. Evaluate

    Evaluate predictions against reference annotations using supervised metrics.

  3. Inspect

    Review thumbnails and polygon outlines across slides; add ground truth and evaluation metrics when available.

02

Flexible use

Use Segmenteer on your own WSI cohort.

Segmenteer supports workflows ranging from predictions-only visual review to reference-based evaluation and benchmarking.

Start with whole-slide images and segmentation predictions. Add GeoJSON ground truth and evaluation metrics when available; the viewer remains useful with predictions alone.
